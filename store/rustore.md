## Короткое описание (≤80)

Управляйте Cursor IDE с телефона: код подключения с ПК, проекты, чат.

## Полное описание

CursorRemote — клиент для удалённой работы с Cursor IDE на вашем компьютере через интернет.

На ПК ставите агент (CursorRemoteAgent), копируете код из трея `CR-XXXX-XXXX:ключ`. На телефоне вставляете полный код — видите карточки проектов и пишете агенту в чате.

- подключение к своему ПК, где уже открыт Cursor;
- список проектов с компьютера;
- чат с агентом, как в IDE;
- код хранится на устройстве в защищённом хранилище.

1 день бесплатно. Далее подписка 234 ₽ на 30 дней — оплата в Telegram-боте HappyCursorRemote_bot. Нужен интернет на телефоне и на ПК с агентом.

Не официальный продукт Anysphere / Cursor IDE. Разработчик: palapalaru@gmail.com

## Для модерации

Тест: на Windows запустить CursorRemoteAgent.exe (релиз на GitHub thekingoffamily/CursorRemote) → ПКМ в трее → «Скопировать код подключения» → в приложении вставить полный код. На ПК должен быть открыт Cursor с проектом. Оплата — через Telegram-бота, не в APK.
